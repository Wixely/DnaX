# DNA X 10.0.0-alpha.7

`DnaX.Uploads` now exposes `mountCustom(view, endpoint, profile, render)` for applications that supply their own native picker, progress rows and controls. The synchronous renderer receives copied queue state and actions for selecting files, pause/resume, cancellation, reselection and dismissal. Transfers and persistence remain browser-owned and independent of Blazor callbacks. The existing `mount` and `UploadPicker` UI remain available.

The host must capture File references in the native change/drop handler and preserve native inputs while the OS picker is open. Call `setPickerOpen(true)` when opening the picker and clear it on cancellation; `addFiles` and `reselect` clear it on selection. Renderer exceptions are isolated from transport processing.

All packages use version `10.0.0-alpha.7`. Uploads remain experimental: the API and journal format are not stable, the disk store is single-process, and actual 50/100 GiB and physical mobile-device acceptance remain outstanding.

Verification: 118 .NET tests passed locally. Chromium verified native input preservation, isolated renderer failures, copied policy state, picker reload barriers and dismissal. The existing default-picker scenario also passed: five files across three profiles after circuit disconnection, including recovery from a lost accepted-chunk response.
